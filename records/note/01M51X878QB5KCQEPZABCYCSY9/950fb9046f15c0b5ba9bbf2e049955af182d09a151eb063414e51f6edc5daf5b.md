## Kendt
- Konteksten er forbedring af brugen af AI i softwareudvikling (01M51X0TQR6KG3S3CTZK5AFNC9@1f15ef884fa2).
- På mødet 22/10: det er ikke et spørgsmål om vi bruger AI eller ej (01M5HPPGD9KTP6ZSQHB3XXD98M@84d6e354e6bb).
- Metrikker bliver dårlige målenheder på grund af lov (01M5HPJQFHC6E3XBTWWY9PN828@8a4b53cf900e); et open source-projekt viser manglende korrelation mellem spørgsmål og effekt (01M5HPM5Z020X8K35YVYA1736H@911fbd9c3ad1).
- Noget er ikke slået igennem i processerne endnu (01M5HPN3QGGJTX6YK20TVS9QQ9@f8e8e4299ad6), og der er stor spredning i erfaringen (01M5HQ6NP420TB6PHAM9X1AANA@7ac423f681f8).
- En AI-agent i GitHub med en code review-skill giver hurtigere code reviews (01M5HQB23KN8BZZVC1TB6TVJBH@d931d1471d0d). DE-teamet laver code review på egne ting (01M5HQBW6X7NBFWAKQRQM34YHH@6a37334a6bcc, 01M5HQBCJZJEP9R9TQCXF2AFQ9@ecb38818443b).
- Smerten ved at skrive dokumentation er blevet meget mindre (01M5HQ0D0PJE5N29RQVJSFPBJS@dd4d9a6f8255). Det er de gamle projekter, der er mindst vedligeholdbare (01M5HQ0076F9PBGDAKVMG1VWA9@c6af06de275f).
